这一页不展示某个具体产品，而是把前面 4 个真实项目里反复出现的工作方式摊开来讲。它不是模板，而是我在动手前真正会问自己的几个问题。

Principles

四条我反复使用的工作原则

01 · 从真实问题出发

拒绝"为造型而造型"。每个项目都从一条用户痛点开始：猫窝源于独居青年养猫的清洁焦虑，相机源于长时间手持的疲劳。先有"为什么"，再谈"长什么样"。

02 · 让技术隐于形态

好的工业设计要求复杂的功能以最克制的姿态出现。相机用模块化机身收纳复杂接口，耳机用一块软质头梁消化结构。技术不是卖点，而是被藏起来的底气。

03 · 用迭代代替灵感

我不相信一次性成型。草图 → 素模 → 线框 → 渲染，每一轮都在推翻自己。失败方案不是垃圾，而是帮最终方案收窄方向的路标（见各项目"失败方案"小节）。

04 · 在真实场景里验证

渲染图再好看，也要回到使用情境：猫窝要放进真实客厅，玩具车要交到孩子手里。用户反馈、试用数据、落地结果，才是设计的终检。

Design → Production

从设计到生产的衔接

产品设计师的价值，在于把设计语言翻译成结构工程师与模具厂能接住的几何。下图把我的工作方式对齐到「外观 → 拆件 → 结构 → 开模 → 包装 → 规格书 → 量产」全链路——前两步由我主导，后几步是我已在项目中铺垫、可快速承接的部分。

01

控制图 / 外观定义

依 Control Drawing 锁定外观与关键尺寸

→

02

3D 外观建模（曲面）

Rhino NURBS 建模，输出了然于形的形态

→

03

产品拆件与结构

模块化 / 卡扣 / 抽屉式分件，定义装配关系

→

04

开模图 / 模具跟进

圆角、出模斜度、壁厚与分件已纳入考量

→

05

包装吸塑设计

分件 / 防护 / 堆叠结构思考可迁移至 blister

→

06

零件规格书

爆炸图层級与标注建立零件清单意识

→

07

验证与量产

用户测试迭代，反馈回流至模具修改

越野车玩具的爆炸图、可开模分件与卡扣公差，即是第 3–7 步在作品中的直接证据。

“我不追求第一眼惊艳，而追求第十次使用仍然顺手。”
