我的优势（对应初级 3D 设计师岗）

1. 全流程独立交付 — 调研、草图、建模、渲染与用户测试迭代均可独立完成（含猫窝真实测试），不是纯概念作业。

2. 拆件与结构思维 — 模块化榫卯、磁吸快拆、抽屉式砂仓、可开模分件与爆炸图已在项目中实践，能衔接结构工程师做拆件与开模图。

3. 量产与模具意识 — 关注圆角、出模、卡扣公差、材质（ABS / TPR）与装配关系，设计阶段即考虑可制造性。

4. 快速学习与协作 — 工具链扎实，实习中熟悉方案到工程的沟通链路，能与结构 / 包装工程师高效对接。

JD Fit · 岗位能力对照

作品集内容 ↔ ZURU 初级 3D 设计师 JD

下表把本作品集的展示项直接映射到招聘 JD 的 6 项工作职责与 5 项任职要求，便于评审快速定位匹配点。其中拆件 / 开模图 / 零件规格书等为可迁移基础能力（已在项目中实践），并非虚构的岗位经验。

一、岗位职责对应

职责 1 · 协助 3D 外观设计
4 个项目外观与结构模型均由本人用 Rhino（NURBS 曲面）建模、Keyshot 渲染；越野车 / 猫窝为个人独立完成，可直接承接 Control Drawing 转 3D。
职责 2 · 产品拆件 + 结构设计 → 开模图
DSLR 模块化榫卯导轨 / 耳机磁吸快拆 / 猫窝抽屉式砂仓 / 越野车可开模分件，均体现拆件、装配与结构取舍。
职责 3 · 包装吸塑设计
越野车 / 猫窝项目含分件、防护与堆叠结构思考，可快速迁移至吸塑托盘（blister）设计。
职责 4 · 模具修改跟进 + 资料修订
各项目均记录「沉淀 / 优化」（卡扣公差、壁厚、吊带张力、行李架卡扣），即模具修改与资料修订的雏形。
职责 5 · 零件规格书（五金 / 塑胶 / 外购件）
越野车爆炸图已建立「外观件 / 结构件 / 电子件 / 易损配件化」的零件层级与标注意识。
职责 6 · 上级交办其他任务
实习与项目制经验，具备按节点交付与跨角色协作习惯。

二、任职要求对应

要求 1 · 专业对口
产品设计本科，课程覆盖人机工程 / 三维建模 / 设计表现 / 产品开发流程。
要求 2 · 3D 软件 + 曲面建模
Rhino NURBS 曲面建模熟练、实际项目经验充分；Creo / ProE 可快速上手（同属参数化 / 特征建模）。
要求 3 · 塑料模具 / 注塑 / 出模
了解注塑基本工艺与出模要求，项目中已应用圆角、分件、卡扣与公差意识。
要求 4 · 产品结构 + 工厂流程
拆件、装配、材质与量产可行性已在项目中验证迭代。
要求 5 · 沟通与协作
鹭达设计实习熟悉方案 → 工程沟通，可与结构 / 包装工程师高效对接。
